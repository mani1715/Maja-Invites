## 1. App entry & router registration

**Entry:** `backend/server.py` — 16,376 lines, 656 KB. Single FastAPI app object, no `create_app()` factory, no lifespan (uses deprecated `@app.on_event`).

- `app = FastAPI(docs_url/redoc_url/openapi_url = None if _IS_PROD)` @ L209. `_IS_PROD` = `ENV` ∨ `APP_ENV` ∨ `ENVIRONMENT` ∈ {production, prod}.
- **97 `app.include_router(...)` calls**, 88 `from X import build_*_router` imports, **218 `@api_router.*` inline routes**, 8 `@app.*` inline routes. Total surface **1,182 routes / 181 namespaces** (`API_SURFACE.md`, generated by `backend/scripts/dump_api_surface.py`).
- Two registration idioms coexist:
  1. **Router-factory**: `build_<x>_router(db, <auth deps>, ...) -> APIRouter` with **full paths baked into decorators** (`@router.get("/api/admin/...")`), included with **no prefix**. This is the dominant pattern (~88 modules).
  2. **`api_router = APIRouter(prefix="/api")`** @ L263 — the inline monolith routes. Included **LAST-ish at L16226**, i.e. *after* ~90 app-level routers.
- **Registration order is load-bearing (Starlette matches in order):**
  - `storage_serve` router registered EARLY at L260 (before `api_router` exists) so `/api/uploads/*` + `/uploads/*` aren't shadowed. Comment says this replaced two `StaticFiles` mounts.
  - `build_event_children_router` MUST be **last of the event routers** (L16312) — its `/api/events/{event_id}/{collection}[/{child_id}[/{action}]]` catch-all swallows `/api/events/plans/{type}`, `/api/events/purchase/verify`, `/api/events/starter-content/{type}`, `/api/events/{id}/money-members`.
  - Middleware added at L16315–16340, **after** all routers (correct for Starlette; `add_middleware` order = reverse execution).
- Module-level side effects at import: `load_dotenv`, `raise RuntimeError` if `SUPABASE_DB_URL` unset, Razorpay client init, Sentry init, `UPLOADS_DIR.mkdir()`.
- **`from __future__ import annotations` is BANNED in router-factory modules** (CLAUDE.md golden rule #4) — breaks FastAPI dep resolution.

**INVARIANT / TRAP:** `get_current_admin` → **string**, `require_admin` → **dict**. Both are passed as `get_current_admin=`/`require_admin=` kwargs into router factories interchangeably; getting it wrong is a silent `TypeError` at request time. `API_SURFACE.md` explicitly annotates this.

**Token issuing (admin/photographer):**
- `create_access_token(data)` HS256, `JWT_SECRET_KEY`, `ACCESS_TOKEN_EXPIRE_MINUTES` (default **60**), auto-adds `jti`.
- **Fail-hard**: module import raises `RuntimeError` if `JWT_SECRET_KEY` is the built-in default, unless `ALLOW_INSECURE_JWT=1`.
- `auth.py` calls its own `load_dotenv(backend/.env)` at import because server.py imports auth *before* its own `load_dotenv`.
- Login sites minting tokens: server.py **L1098** (`/api/admin/login`), **L1295** (`/me` supabase), **L1402** (sync-supabase), **L1750** (register). Each then best-effort calls `issue_session(...)`.
- **Hybrid Supabase**: `get_current_admin*` tries `verify_supabase_jwt` (`auth_supabase.py`, JWKS ES256/RS256 or legacy HS256) first, maps claims→`admins` by `supabase_user_id` then `email` (and back-stamps `supabase_user_id`); falls through to legacy HS256 on `SupabaseAuthError`.
- **Revocation**: `POST /api/admin/logout` upserts `jti` into collection `jwt_blacklist`; `_is_jwt_blacklisted` checks it and **fails open** on any error.
- Client tokens rejected on admin deps via explicit `payload.get('typ')=='event_client'` check.

## 3. Middleware stack

Registered L16315–16340 (execution order is reverse of registration):
1. `CORSMiddleware` (outermost)
2. `AbusePreventionMiddleware`
3. `BotDetectionMiddleware`
4. `SecurityHeadersMiddleware` (innermost)

All three custom ones in `backend/security_middleware.py` (441 ln), `BaseHTTPMiddleware`.

- **SecurityHeaders**: enforcing `Content-Security-Policy` (with `unsafe-inline`/`unsafe-eval`), X-Frame-Options DENY, nosniff, Referrer-Policy, X-XSS-Protection, Permissions-Policy, HSTS when `x-forwarded-proto==https`. Cache-Control: `/api/uploads/*` → 1d immutable; `/api/public/*` + `/api/invite/*` GET → `max-age=30, s-maxage=60`.
- **BotDetection**: ALLOWED_BOTS (14 crawlers) / BLOCKED_BOTS (15 incl. **`curl`, `wget`, `python-requests`, `axios`, `okhttp`**) → 403. Exempt prefixes: `/api/admin`, `/api/auth`, `/api/health`, `/docs`, `/openapi.json`, `/robots.txt`, `/sitemap.xml`, `/api/invite`, `/api/public`, `/api/uploads/`, `/api/ws/`, `/api/rsvp`, `/api/payments/razorpay-webhook`, plus `/api/live-gallery/desktop-upload` with `X-Uploader-Token`.
- **AbusePrevention**: per-IP fixed windows — >1000/hr → 30min soft block; >200/min → 10min; >300 `/invite/` per hr → 30min. **State is process-local dicts `request_tracking` / `soft_blocks` — NOT Redis.** Exempt list is a hardcoded 22-prefix allowlist (`/api/portfolio`, `/api/store`, `/api/pixora`, `/api/studio`, `/api/gallery`, `/api/users`, …).
- **CORS**: `CORS_ORIGINS` csv, default `http://localhost:3100,http://localhost:3000`. If `*` (or empty) → `allow_credentials=False`. Logs a warning if wildcard in prod. **Cookie-based buyer login breaks silently under `CORS_ORIGINS="*"`** (documented in START_HERE.md §2).
- Global `@app.exception_handler(Exception)` → generic 500 + `error_id` uuid12, full traceback logged server-side.
- No auth middleware — auth is purely per-route `Depends`.

## 6. Postgres — `backend/pg_adapter.py` (941 ln)

Mongo-compatible async facade over Postgres JSONB. **Pool: `asyncpg.create_pool`.**

- Built in server.py L173: `db = _PGDatabase.lazy(SUPABASE_DB_URL, min_size=DB_POOL_MIN|1, max_size=DB_POOL_MAX|20)`; connected in `@app.on_event("startup") _connect_pg_pool()` → `await db.ensure_connected()`. Lock-guarded, idempotent, also connects on first query.
- `client = None` retained for legacy references (Mongo removed).
- Table shape: `(id TEXT PK, data JSONB, created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ)` + **generated STORED columns** for hot fields. `_table_columns()` caches `column_name → data_type` per table; promoted columns are used in WHERE instead of JSONB paths.
- **`ensure_table(name)` auto-creates any unknown collection on first use** (`CREATE TABLE IF NOT EXISTS` + `gin(data)` index), swallowing `UniqueViolation`/`DuplicateTable` from the known non-atomic race. → **new collections need zero migration.**
- Supported ops: `find_one/find/insert_one/insert_many/update_one/update_many/delete_one/delete_many/count_documents/distinct/find_one_and_update`; Cursor `.sort().skip().limit().to_list()`, `__aiter__`.
- Operators: `$eq $ne $gt $gte $lt $lte $in $nin $exists $regex $or $and $not`; updates `$set $inc $unset $push $pull $addToSet $setOnInsert`. **Anything else raises `NotImplementedError`** — no `$expr`.
- `aggregate()`: fast path pushes `[$match?, $group, $sort?, $limit?]` to SQL GROUP BY; otherwise loads all matched docs into Python and executes `$match/$group/$sort/$skip/$limit/$count/$project` in-process. Other stages → `NotImplementedError`.
- **`create_index()` is a NO-OP** (indexes declared in `db/schema.sql`).
- `_check_ident` / `_check_field` allowlists guard the f-string SQL (this was a 2026-07-30 hardening fix).
- Schema file: **`microservices/db/schema.sql`** (465 ln, **33 tables**) — auto-applied via `/docker-entrypoint-initdb.d/01-schema.sql` on first PG init. Root `db/` holds only `seed_accounts.sql`.

**Known adapter gotchas (from CLAUDE.md / MULTI_DRIVE_STORAGE_DESIGN.md):**
- `find_one_and_update` is **NOT race-safe** for capacity guards → raw conditional UPDATE used instead in storage pool.
- Boolean equality on generated boolean columns mis-binds → filter booleans in Python.

## 12. What breaks if you add new routers/workers

1. **Registration order.** New app-level routers registered *before* `app.include_router(api_router)` (L16226) shadow any `/api/...` path the inline monolith already serves. Anything added *after* the event-children catch-all (L16312) is fine; anything with a `/api/events/...`-shaped path registered *after* it is dead.
2. **Middleware must stay last.** `add_middleware` calls sit at L16315+; inserting router registrations after them is fine, but adding middleware before routers changes the stack order.
3. **Dep signature mismatch.** Pass `require_admin` (dict) vs `get_current_admin` (str) correctly — no type checking catches this. `require_super_admin` returns a str.
4. **No prefix convention.** Router factories bake full `/api/...` paths into decorators and are included with no prefix. A new router included *with* a prefix will double-prefix if it follows the house style.
5. **New collections need no migration** — `ensure_table` auto-creates them. But they get **no promoted columns** (full JSONB scans) and **no TTL/cleanup** (`create_index` is a no-op). Add generated columns to `microservices/db/schema.sql` for any hot field — note that file only runs on *first* PG init, so an existing volume needs a manual `ALTER TABLE`.
6. **Adapter operator ceiling.** No `$expr`, no `$lookup`, no `$unwind`, no `$facet`. Non-trivial aggregation either hits the SQL fast path (`$match?→$group→$sort?→$limit?`) or loads every matched row into Python.
7. **New background workers must be leader-locked** with `cache_backend.acquire_lock` — prod runs 4 uvicorn workers and every `on_event("startup")` fires in each. Follow the `scheduler:gallery:leader` pattern (acquire + heartbeat at TTL/2), not the `_expiry_sweep_loop` pattern.
8. **Connection budget.** `db max_connections=200`; core is 4 workers × `DB_POOL_MAX=10` = 40; the 5 microservice stubs each open their own pool. A new service or a raised `DB_POOL_MAX` eats into that headroom.
9. **Redis has no persistence** (`--save "" --appendonly no`). Anything stored there (OTPs, buffered view counts, rate-limit windows, leader locks) is lost on restart. Do not put durable state in it.
10. **New routes need Caddy/gateway awareness.** A new hot public prefix will go `caddy → gateway → core` (two hops) unless added to the Caddyfile bypass list. A new **WebSocket** route must be bypassed to core in the Caddyfile — httpx in the gateway cannot upgrade.
11. **Bot middleware blocks tooling.** `curl`, `python-requests`, `axios`, `okhttp`, `wget` UAs get 403 on any non-exempt path — new routes are unreachable from scripts/tests unless a browser UA is spoofed or the prefix is exempted.
12. **`from __future__ import annotations` is forbidden** in router-factory modules.
13. **Two data layers to keep in sync** if you touch the adapter: `backend/pg_adapter.py` and `microservices/shared/db.py`.
14. **Regenerate `API_SURFACE.md`** after adding routes: `cd backend && python scripts/dump_api_surface.py`.
